# 手动测试清单（M1–M6）

目标：在微信开发者工具里走通主流程，并确认免费 / Mock Pro、门控、清空、导出和隐私文案符合任务书。

## 0. 准备

1. `cd today-role && npm install && npm run check`，应全部通过。
2. 微信开发者工具「导入项目」，目录选 `today-role/` 根目录，AppID 用测试号即可。
3. 打开调试器 Console，后续每个页面切换时观察是否报错。
4. 如需从干净状态开始：进入「我的」→「清空全部数据」。

> 「载入演示数据」会覆盖现有记录（Mock 权益保留），仅用于开发测试。演示数据是最近 45 天：工作日常见「工作 × 紧绷」，周三固定为低点，周末回到独处 / 家庭。

## M1 项目脚手架

- [ ] 编译成功，无红色报错。
- [ ] 底部有 3 个入口：记录 / 角色 / 我的，均可点击切换。
- [ ] 从「我的」能进入付费权益页、本月角色卡；从今日结果能进入周快照 / 月卡。
- [ ] 6 个页面均可打开：记录、今日碎片、周快照、月卡、付费页、设置。
- [ ] Console 无 `Cannot find module`、`Page is not defined`、类型编译错误。

## M2 每日记录 + 今日碎片

- [ ] 首页选 1 个状态 + 1 个场景，点保存，5 秒内完成；结果页立即出现标签和解释。
- [ ] 解释中同时出现当天状态和场景，例如「今天你在「工作」场景下记录为「紧绷」……」。
- [ ] 解释中有最近 7 天次数锚点（如「这个组合出现 3 天」），下方有 3 条 DATA ANCHORS。
- [ ] 同一天再次保存不同状态 / 场景：仍只有 1 条当天记录，按钮显示「更新今天的记录」。
- [ ] 保存后返回首页，原有选择被回填。
- [ ] 备注输入 100 字被截断，计数显示 `100 / 100`。
- [ ] 备注内容不会出现在今日碎片的解释里（可在备注写「测试备注XYZ」，结果页应只在「你写下的一句话」出现）。
- [ ] 不选状态或场景直接保存，出现「先选一个状态 / 再选一个场景」提示，不写数据。
- [ ] 在开发者工具 Storage 面板查看 `today-role.v1.entries`：同日只有 1 条。

## M3 周快照

- [ ] 干净状态下只记录 2 天，进入「角色」：显示「还差 1 天」，进度条和「已记录 2 天 / 满 3 天可生成」。
- [ ] 点「去记录今天」能回到记录页。
- [ ] 记录到 3 天后，周快照出现 2 个 Pattern，每个描述都含数字。
- [ ] 载入演示数据后进入「角色」：显示 7 天、2 个 Pattern，其中 1 个带「反常识」标签，标题为「低点不在周初或周五」或「场景落差」。
- [ ] 若数据没有明显反常识，页面不硬编故事：第二个 Pattern 显示「最稳定与最波动的场景」或「暂无可验证的反常识模式」。
- [ ] 7 天窗口外的旧记录不参与统计（可对比单位测试，或手动只保留最近 2 天 + 很久以前 5 天，仍显示门控）。

## M4 月角色卡

- [ ] 干净状态下记录不足 10 天，进入月卡：显示「还差 X 天」，不展示分布。
- [ ] 载入演示数据后进入月卡：显示当月记录天数（示例日期下为 18 天）、6 个状态分布条、Top 2 场景、例外 / 张力、一条轻量建议。
- [ ] 分布条百分比合计约 100%（允许四舍五入误差），各状态天数和为当月记录天数。
- [ ] 建议带具体日期 / 星期 / 天数锚点，例如「下周一（11-23）……」。
- [ ] 免费状态下，深度解读区域显示锁定卡片（触发 / 共现、历史对比、3 条完整建议），不出现具体 Pro 内容。
- [ ] 页面底部有「仅供自我观察，不构成医疗建议」，没有诊断、人格类型、治疗类词汇。

## M5 权益与设置

- [ ] 「我的」→「查看 / 切换 Mock Pro」→「模拟开通 Pro」：弹窗明确「不接微信支付、不产生费用」，确认后显示 Mock Pro。
- [ ] 返回月卡：深度解读出现触发 / 共现观察、本月 vs 上月、完整行动建议 3 条。
- [ ] 上月记录不足 3 天时，历史对比区域显示「数据不足 / 少于 3 天」，不编造对比；该项由单元测试覆盖（手动需构造仅本月有记录的数据）。
- [ ] 关闭 Mock Pro：月卡恢复锁定卡片，但分布 / Top 场景 / 张力 / 一句建议仍完整可见。
- [ ] 关闭 Mock Pro 后记录数据仍在，不被删除。
- [ ] 「我的」→「导出 JSON」：提示已复制到剪贴板；粘贴到文本编辑器，JSON 可解析，包含 `schemaVersion`、`entries`、`entitlement`、`weeklySnapshots`、`monthlyCards`。
- [ ] 导出内容与页面统计条数一致。
- [ ] 「我的」→「清空全部数据」：确认后提示已清空，累计 0 天，本月 0 天，权益回到免费版。
- [ ] 清空后在开发者工具 Storage 面板搜索 `today-role.v1.`：无残留键（其他应用键不受影响）。
- [ ] 清空后进入周快照 / 月卡：都显示门控，不出现旧数据；今日结果页显示「今天还没有记录」。
- [ ] 清空后重新记录 1 天，功能正常，说明清空没有破坏仓储。

## M6 测试与文档

- [ ] `npm run typecheck` 无错误。
- [ ] `npm test` 全部用例通过（当前 32 个，包含端到端流程）。
- [ ] `npm run check:structure` 通过：页面四件套、tabBar、WXML 标签 / 事件、文案红线、隐私入口、无网络调用。
- [ ] README 的「快速开始」「命令」「数据层切换」「生成器切换」与项目实际一致。
- [ ] 按 README 的「数据层：本地 / 云端切换」能把 `dataMode` 改为 `cloud` 并看到明确报错，而不是静默写本地。
- [ ] 把 `generatorMode` 改为 `llm` 会得到明确未接入错误；改回 `rule` 恢复正常（仅验证切换点，不要求接入 LLM）。

## 隐私与红线专项

- [ ] 全程断网（开发者工具 Network 面板无请求；源码无 `wx.request` / `wx.login`）。
- [ ] 不弹登录、不请求头像 / 昵称 / 手机号 / 位置。
- [ ] 今日碎片、周快照、月卡、Pro 文案中不出现：诊断、抑郁、焦虑、人格类型、治疗、障碍等词。
- [ ] 不出现「你就是……的人」「你属于……」等定性句式。
- [ ] 不出现分享奖励、分享解锁、排行榜、评论、真人咨询入口。
- [ ] 付费页无微信支付按钮，只有 mock 开关。
- [ ] 备注不会进入生成文案，也不会出现在任何分享内容里。

## 已知限制（手动测试时不必视为缺陷）

- 演示数据按「今天」倒推 45 天。若当天是每月 1–9 日，当月记录必然不足 10 天，月卡门控会正确显示「还差 X 天」，这是产品规则，不是数据错误。
- 周快照用「最近 7 天滚动窗口」，与自然周不完全一致；`weekStart` 只作为缓存键。
- Mock Pro 只在本机，清空或换设备即失效。
- 月份只展示当前月；Pro 历史对比在本月页内展示上月汇总。
